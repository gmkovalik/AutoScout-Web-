# Project notes

The original AutoScout Python source was supplied by the project owner in this conversation. `backend/autoscout_engine.py` is a browser-backend adaptation of its AutoScout 4.1.0 single-file source: the Tkinter GUI portion is omitted while the statistics, FTCScout API client, prediction, session, standings, alliance, and analysis logic is retained. The original copyright and branding comments remain in the engine source.

The public AutoScout Google Sites page was used as a design/content reference for the landing page and its CAP/FTC scouting messaging. This web project is an independent implementation, not the original v2.2.3 desktop release.
